## The Stack

Building agentic products requires thinking in layers, much like the traditional software stack but with new AI-native concerns.

### Layer 1: Foundation Models
The base LLMs that power reasoning. Your choice here affects everything above — cost, latency, capability ceilings, and reliability.

**Key decisions:** Model selection, hosted vs self-hosted, fallback strategies, fine-tuning vs prompting.

### Layer 2: Orchestration
How you coordinate LLM calls, tool use, and multi-step workflows. This is where agent frameworks (LangGraph, CrewAI, custom) live.

**Key decisions:** Single vs multi-agent, sync vs async, state management, error recovery.

### Layer 3: Tools & Integrations
The actions your agent can take in the real world. APIs, databases, file systems, code execution, web browsing.

**Key decisions:** Tool design (input/output contracts), authentication, rate limiting, sandboxing.

### Layer 4: Knowledge & Memory
How your agent accesses information (RAG, knowledge bases) and remembers context (conversation history, long-term memory).

**Key decisions:** Chunking strategy, embedding models, vector DB choice, memory architecture.

### Layer 5: Guardrails & Safety
Input validation, output filtering, hallucination detection, content moderation, and human-in-the-loop gates.

**Key decisions:** Where to place guardrails, latency budget for safety checks, escalation paths.

### Layer 6: User Experience
How humans interact with and trust the agent. Transparency, explainability, feedback loops, progressive disclosure of capabilities.

**Key decisions:** How to show agent "thinking," confidence indicators, undo/correction mechanisms.

## The Product Manager's Job

At each layer, the PM's job is to make **tradeoff decisions** that optimize for the user while respecting technical and business constraints. The agentic product stack is new, but the PM skills — prioritization, user empathy, technical judgment — are the same.
